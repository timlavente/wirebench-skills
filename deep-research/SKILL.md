# Deep research

Pick one mode. Research, plan, or audit.

1. Read the staged add-ons and whether a secret slot is armed. Names only.
2. If a freeze exists and the operator asked to audit it, read that freeze only. Ignore later edits.
3. Return a title, a short summary, three sections, findings, and four or five steps.
4. Findings are note, watch, or block. Use block only for a secret leak or opening a private network.
5. Flag an empty surf allow-list as watch.
6. Do not browse the web unless the operator also asked for a surf.
7. Do not invent secret values. If a key is missing, say it is missing.
