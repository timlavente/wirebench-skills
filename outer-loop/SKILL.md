# Outer loop

1. Research the ask.
2. Write a phased plan. Stop between phases.
3. Audit secrets, the surf allow-list, Tailscale, and xCloud scopes.
4. If a page must be checked, surf it with Playwright and stay on the allow-list.
5. Stop on any block finding.
6. Ask before a tailnet join, an xCloud write, a payment, a post, or a delete.
